# 🛒 Repositorio de Desarrollo Web - UCompensar

¡Hola! Este repositorio contiene los proyectos prácticos, laboratorios y entregables desarrollados durante mi formación académica en la **Técnica Profesional en Programación de Software** y la **Tecnología en Desarrollo Web y Móvil**.

## 📁 Estructura del Portafolio Técnico Real

*   **🛒 QuickShop (Simulador de Tienda):** Proyecto final donde implementé lógica frontend interactiva consumiendo la API pública de *DummyJSON*. Incluye un sistema de autenticación de prueba (Login/Logout), carga dinámica de productos desde el servidor y gestión del estado del carrito de compras.
*   **📊 Tabla Periódica Interactiva:** Ejercicio avanzado de maquetación web estructurada utilizando HTML5 y CSS3, aplicando propiedades avanzadas de Grid y Flexbox para la organización y diseño responsivo.
*   **🪟 Ventana Modal y Formulario:** Componentes enfocados en la experiencia de usuario (UX/UI), validación en la captura de datos del formulario y manipulación del DOM mediante JavaScript.
*   **📰 Página de Noticias Adaptable:** Ejercicio práctico enfocado en el diseño web adaptable (Responsive Design) para la correcta visualización en dispositivos móviles y pantallas de escritorio.

## 🛠️ Tecnologías Aplicadas
*   **Frontend:** HTML5, CSS3, JavaScript (ES6)
*   **Conceptos Clave:** Integración de APIs (JSON), Manipulación del DOM, Diseño Responsivo.
